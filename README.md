# Alt Text Generator

A local AI-powered image alt text generator built using **LLaVA** and **Ollama**.

Generate descriptive alt text for images to improve web accessibility, with AI processing running locally on your machine.

## Features

- Generate image descriptions automatically.
- Improve accessibility for screen reader users.
- Run AI locally using Ollama and LLaVA.
- No cloud API costs required for local inference.

## Getting Started

1. Install [Ollama](https://ollama.com/).
2. Download the LLaVA model:

   ```bash
   ollama pull llava
   ```

3. Start Ollama and run the application according to the project's setup instructions.

## Why This Project?

Writing meaningful alt text for every image can be time-consuming. This project explores how local AI can make accessible web content easier to create without relying on paid cloud APIs.
